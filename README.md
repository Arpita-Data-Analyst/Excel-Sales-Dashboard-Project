# Excel Sales Dashboard Project

## Project Overview
This project demonstrates sales data analysis and dashboard creation using Microsoft Excel.

## Tools Used
- Microsoft Excel
- PivotTables
- Pivot Charts
- Data Visualization

## Workbook Structure
- **Data:** Original sales dataset
- **Pivot Table:** Summarized sales information
- **Dashboard:** Visual representation of sales insights

## Objective
To organize, analyze and present sales data through an interactive Excel dashboard.

## Key Features
- Sales data analysis
- PivotTable summaries
- Interactive visualizations
- Dashboard reporting
